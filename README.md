# What Is This
This [Obsidian](https://obsidian.md/) vault is a collection of Torn rules as they are enforced (or not).

# Why Make This
The [official rules page](https://www.torn.com/rules.php) is designed to be concise and staff [[Rules Philosophy|intend]] to leave some ambiguity so players aren't incentivized to push the bounds.

However, this approach [creates some practical issues](https://www.torn.com/forums.php#/p=threads&f=2&t=16604899&b=0&a=0&start=500&to=27933547):
```
[...] the years of tribal knowledge that have amassed from this approach are unsustainable (and IMO, already out of hand). It feels as though we have to become rules lawyers and study the case law to not accidentally misstep.

It would be really helpful to have a long-form collection of decisions and discussions like this one, parallel to the shorter rules page you prefer to maintain.

Maybe this would be better off as a community-run project, but that comes with the downsides of lack of authority and losing your intent in translation. Curious if you have any thoughts on it first.
```

Bogie's response upon following up privately: `It's my opinion that the rules list is sufficient`.

# Disclaimer
This is a best-effort attempt to catalogue nuance in the rules for the community's benefit. No guarantees are made and staff may change the rules, interpretation, and enforcement at any time.
